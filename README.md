# No Dim

Client-side Fabric mod for Minecraft 26.3. Removes the dark gradient behind the inventory and other in-world screens.

Works with Lunar Client's Fabric profile. Needs Fabric Loader 0.20.1+ and Java 25.

## Build

Push to GitHub. The **Actions** tab builds the mod. Download the `nodim-jar` artifact from the latest run
and use the main jar (not the `-sources` jar).
